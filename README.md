# 🚀 NexusDesk — Smart Workspace & Analytics Hub

> Live Demo: [nexusdesk.vercel.app]() 
> Tech Stack: Next.js (App Router), TypeScript, Tailwind CSS, Zustand, Recharts, React Hook Form, Zod

---

 📌 Overview
NexusDesk adalah platform *SaaS Workspace* modern yang dirancang untuk membantu pengelolaan transaksi bisnis serta pembuatan aset visual secara *real-time*. 

Proyek ini dibangun untuk mensimulasikan kebutuhan sistem industri B2B nyata, berfokus pada **performa tinggi, manajemen state global yang bersih, validasi data yang ketat, serta pengalaman pengguna (UI/UX) yang interaktif**.

---

✨ Key Features

📊 1. Analytics & Data Management Hub
- Interactive Data Table: Fitur pencarian instan (*real-time search*), penyaringan status transaksi, dan manajemen entitas data.
- Visual Analytics: Dashboard statistik dengan grafik batang (*bar chart*) interaktif menggunakan Recharts.
- Robust Form Validation: Form penambahan data transaksi dengan validasi *client-side* ketat menggunakan React Hook Form dan schema Zod.
- Global State Management: Sinkronisasi state transaksi dan preferensi pengguna secara *real-time* di seluruh komponen menggunakan Zustand.

🛠️ 2. Interactive Utility Module (Banner Generator)
- Live Canvas Preview: Tool kustomisasi teks dan kombinasi warna banner secara *live preview*.
- Asset Export: Ekspor hasil desain banner secara langsung.

 🎨 3. UX & Technical Polish
- Dark / Light Mode: Dukungan penuh mode tampilan gelap dan terang yang tersimpan di `localStorage`.
- Fully Responsive: Layout teroptimasi untuk perangkat Desktop, Tablet, hingga Mobile.
- Type-Safe Development:Dibuat 100% menggunakan **TypeScript** untuk meminimalisir *runtime error*.

---

 🛠️ Tech Stack & Libraries

- Framework: Next.js 15 (App Router)
- Language: TypeScript
- Styling: Tailwind CSS, Lucide Icons
- State Management: Zustand
- Form Handling: React Hook Form + Zod
- Data Visualization: Recharts
